# Scalar–Gauss–Bonnet gravitational memory from full binary-black-hole mergers

**Accepted:** 2026-08-31 01:17 +03:00  
**Classification:** strong-field test / scalar–Gauss–Bonnet modified gravity / gravitational waves  
**Source quality:** peer-reviewed primary literature — *Physical Review D* 114, 044094 (published 2026-08-26)  
**Significance:** high

## Development

Gasparotto et al. present the first calculation of gravitational-wave memory from full inspiral–merger–ringdown waveforms in a theory beyond general relativity, using scalar–Gauss–Bonnet gravity. Starting from general Horndeski memory formulae, they derive explicit tensor null-memory expressions and evaluate them on numerical-relativity waveforms for shift-symmetric and dynamically scalarizing binary black holes.

For the largest deviations in their dataset, the final memory amplitude differs from GR by a few percent, reaching about **4%** relative to the best-matching GR template. More importantly for detectability, including the memory contribution increases the GR-vs-scalar–Gauss–Bonnet waveform mismatch by **more than an order of magnitude**. The authors identify third-generation detectors, especially for lower-mass binaries, as the most promising regime.

The direct scalar contribution to tensor memory is strongly suppressed in the systems studied; the dominant modification instead comes indirectly from altered nonlinear merger dynamics.

## Why this clears the significance threshold

- It is a peer-reviewed primary result, not a forecast summary or secondary report.
- It establishes a **new observable channel** for strong-field tests of modified gravity using complete merger waveforms.
- The >10× mismatch enhancement from including memory is materially relevant to future discrimination of GR from scalar–Gauss–Bonnet gravity.
- It supplies detector-facing quantitative predictions rather than only formal field-equation differences.

## Deduplication / comparison with prior watcher results

This is distinct from previously surfaced modified-gravity GW work focused on propagation effects and stochastic-background spectra for Einstein Telescope / Cosmic Explorer. The new result probes **nonlinear binary-merger dynamics and persistent gravitational-wave memory**, so it adds an independent strong-field observable rather than repeating the earlier propagation channel.

It also differs from prior Horndeski/DHOST cosmology results: although the memory formulae originate in Horndeski gravity, the novelty here is their concrete application to numerical-relativity inspiral–merger–ringdown waveforms in scalar–Gauss–Bonnet gravity.

## Limits

- The predicted memory deviations are only a few percent in the explored systems.
- Detectability is mainly prospective for third-generation instruments; this is not a current observational detection of modified gravity.
- The direct scalar-memory contribution is subdominant in the studied parameter space.
