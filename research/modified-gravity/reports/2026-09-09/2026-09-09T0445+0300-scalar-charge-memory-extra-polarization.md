# Scalar-charge memory as an extra-polarization modified-gravity diagnostic

**Accepted:** 2026-09-09 04:45 +03:00  
**Classification:** simulation / interpretation / observation-facing strong-field test / modified gravity / scalar polarization / gravitational memory  
**Source quality:** peer-reviewed primary literature — *Physics Letters B* 880, 140793 (published 2026-09-01); technical preprint arXiv:2605.07778  
**Significance:** high

## Development

Zosso et al. study compact-binary gravitational memory in Ricci-coupled scalar–Gauss–Bonnet gravity, an extension of scalar–Gauss–Bonnet gravity that supports an additional observable scalar breathing polarization. Using numerical-relativity binary-black-hole waveforms, they show that the merger-induced change in the system's asymptotic scalar charge produces a persistent scalar-memory contribution.

For a GW150914-like binary, the scalar-memory signal develops on the same observational timescale as the tensor memory and reaches an amplitude comparable to the previously studied scalar–Gauss–Bonnet correction to tensor memory. Across a broader range of source and detector configurations, this extra contribution can substantially increase the total departure from the GR memory prediction.

The paper identifies a model-independent mechanism behind the result: whenever a compact-binary merger changes the asymptotic charge of an additional gravitational field, and that field sources an observable extra polarization, the charge jump can generate a leading low-frequency memory signature.

## Why this changes the picture

The repository already contains the peer-reviewed full-merger scalar–Gauss–Bonnet memory result (*Phys. Rev. D* 114, 044094), which found that the direct scalar contribution to **tensor** memory is strongly suppressed in its explored systems and that the dominant beyond-GR effect comes indirectly from modified nonlinear merger dynamics.

The present result is not a duplicate. Ricci-coupled scalar–Gauss–Bonnet gravity opens an **additional scalar breathing channel** whose memory is sourced by the change in asymptotic scalar charge. This means the practical modified-gravity memory hierarchy is broader than “tensor memory corrected by altered merger dynamics”: a theory with an observable extra polarization can place a persistent charge-memory signal in a separate detector channel and make low-frequency memory a leading discriminator.

Operationally, modified-gravity waveform studies should therefore track both:

1. corrections to the usual tensor memory, and
2. memory carried by any extra propagating polarization associated with a changing asymptotic charge.

Discarding the second channel can underestimate the measurable beyond-GR deviation.

## Limits

- This is a theory-specific numerical study, not a detection of modified gravity.
- The quantitative amplitude depends on the Ricci-coupled scalar–Gauss–Bonnet parameter space and on the source configuration.
- Detector-level significance still requires realistic low-frequency noise, calibration, subtraction and parameter-estimation studies.
- The general “charge jump → extra-polarization memory” mechanism is physically well motivated by the calculation, but its quantitative strength must be re-established theory by theory.
